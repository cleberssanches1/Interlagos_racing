Integracao de Euler por Frame

void PRigidBody::tick(float delta)
{
  // Velocidade linear: F = ma => dv = (F/m + g) * dt
  linvel += (accum_force * mass_inv + sim.gravity) * delta;
  pos += linvel * delta;

  // Velocidade angular: torque / I = alpha
  vec3f ang_accel = vec3f(
    accum_torque.x * angmass_inv.x,
    accum_torque.y * angmass_inv.y,
    accum_torque.z * angmass_inv.z);
  angvel += ang_accel * delta;

  // Orientacao: aplicar delta de angulo (quaternion)
  quatf angdelta;
  angdelta.fromThreeAxisAngle(angvel * delta);
  ori = ori * angdelta;

  // Zerar acumuladores
  accum_force = accum_torque = vec3f::zero();
}

Tensor de Inercia

O tensor e diagonal (3 componentes independentes). Calculado a partir das dimensoes do modelo:

angmass.x = y * z * mass * 0.4 (roll)
angmass.y = z * x * mass * 0.4 (pitch)
angmass.z = x * y * mass * 0.4 (yaw)
angmass_inv = 1.0 / angmass

Forca aplicada em ponto

addForceAtPoint(frc, wpt)
Gera tanto forca linear quanto torque:
torque += (wpt - pos) x frc

Vel. linear em ponto

getLinearVelAtPoint(wpt)
= linvel + angvel x (wpt - pos)
Essencial para calcular velocidade da roda

Diferenca chave para o Interlagos: O Trigger Rally usa corpo rigido completo com 6 graus de liberdade. O Interlagos usa modelo planar + vertical separados (2D + altura), sem acoplamento de roll/pitch. Isso e CORRETO para Saturn — roll/pitch sao calculados apenas visualmente.

3.Trigger Rally — Friccao de Roda

Decomposicao em Eixos da Superficie

Para cada roda em contato com o terreno:

// 1. Eixos locais da superficie no ponto de contato
vec3f surf_forward = tci.normal ^ rightdir;   // forward na superficie
surf_forward.normalize();
vec3f surf_right = surf_forward ^ tci.normal; // lateral na superficie
surf_right.normalize();

// 2. Velocidade do ponto de contato (inclui vel. angular do corpo)
vec3f ptvel = body->getLinearVelAtPoint(wclip);
// 3. Adicionar vel. tangencial da roda girando
ptvel += surf_forward * (-wheel.spin_vel * typewheel.radius);

// 4. Componentes de velocidade de escorregamento
vec3f surfvel(
  ptvel * surf_right,    // slip lateral
  ptvel * surf_forward,  // slip longitudinal
  ptvel * tci.normal);   // velocidade normal (penetracao)

// 5. Forca normal (suspensao) + amortecimento
float perpforce = suspension_force;
if (surfvel.z < 0.0f) perpforce -= surfvel.z * typewheel.dampening;

// 6. Friccao = -slip_vel * 10000, limitada por normal * 1.0
vec2f friction = vec2f(-surfvel.x, -surfvel.y) * 10000.0f;
float maxfriction = perpforce * 1.0f;
float leng = friction.length();
if (leng > 0.0f && leng > maxfriction)
  friction *= (maxfriction / leng) + 0.02f;  // clamp circular + pequeno overshoot

// 7. Aplicar forca total no ponto de contato
frc += tci.normal * perpforce + surf_right * friction.x + surf_forward * friction.y;

// 8. Retroalimentar a roda (reducao de spin por atrito)
wheel.spin_vel -= (friction.y * typewheel.radius) * 0.1f * delta;

Drive do Motor

// Adicionar torque de tracao a cada roda
wheel.spin_vel += drivetorque * typewheel.drive * delta;

// Freio: reduzir spin_vel gradualmente
float desiredchange = (state.brake1 * brake1 + state.brake2 * brake2) * delta;
if (wheel.spin_vel > desiredchange) wheel.spin_vel -= desiredchange;
else if (wheel.spin_vel < -desiredchange) wheel.spin_vel += desiredchange;
else wheel.spin_vel = 0.0f;
Principio da friccao no Trigger Rally: A friccao e calculada como rigidez infinita (K * slip * 10000) limitada pelo coeficiente de atrito estatico. Isso e matematicamente semelhante ao modelo de Pacejka em baixo slip (regiao linear), sem o overhead da formula magica.
4.Trigger Rally — Colisao de Corpo (VCLIP_BODY)

Sistema de Clips

O carro possui pontos de colisao fixos no espaco local (clips). Cada clip e um ponto que, quando penetra o terreno, gera reacao de colisao.

VCLIP_BODY

Pontos da carroceria (laterais, frente, traseira). Gera forca normal + friccao. Usado para colisao geral com terreno e paredes.

VCLIP_DRIVE_LEFT / RIGHT

Tank drive: empurra o clip na direcao do drive com steering. Usado em veiculos sem rodas convencionais.

// VCLIP_BODY: forca de colisao com decomposicao de superficie
vec3f rightdir;
if (tci.normal.x > 0.5f) rightdir = vec3f(0.0f, 1.0f, 0.0f);
else                        rightdir = vec3f(1.0f, 0.0f, 0.0f);

vec3f surf_forward = tci.normal ^ rightdir;   surf_forward.normalize();
vec3f surf_right   = surf_forward ^ tci.normal; surf_right.normalize();

vec3f surfvel(ptvel * surf_right, ptvel * surf_forward, ptvel * tci.normal);

float perpforce = depth * clip.force - surfvel.z * clip.dampening;

if (perpforce > 0.0f) {
  vec2f friction = vec2f(-surfvel.x, -surfvel.y) * 10000.0f;
  float maxfriction = perpforce * 0.9f;  // corpo: 0.9 (menos grip que roda 1.0)
  float leng = friction.length();
  if (leng > 0.0f && leng > perpforce * 1.2f)
    friction *= (maxfriction / leng);

  frc += tci.normal * perpforce + surf_right * friction.x + surf_forward * friction.y;

  CLAMP_LOWER(crunch_level, perpforce * 0.00001f);
}

body->addForceAtPoint(frc, wclip);

Condicao de Contato

// Colisao ocorre SOMENTE quando o clip esta abaixo da superficie
if (wclip.z <= tci.pos.z) {
  float depth = (tci.pos - wclip) * tci.normal; // profundidade de penetracao
  // ... calcular reacao ...
}

Colisao com Paredes

O mesmo mecanismo VCLIP_BODY serve para paredes. Quando tci.normal e horizontal (parede), a reacao e automaticamente convertida em:

  • Forca normal: empurra o carro para longe da parede (tci.normal * perpforce)
  • Friccao lateral: desacelera o movimento paralelo a parede (surf_right * friction.x)
  • Friccao longitudinal: desacelera o movimento de deslizamento ao longo da parede (surf_forward * friction.y)
Elegancia do sistema: Nao ha codigo especial para "colisao com parede" vs "colisao com chao" — o normal do terreno (tci.normal) determina automaticamente como a reacao e decomposta. Se a normal for vertical = chao. Se horizontal = parede.
5.Trigger Rally — Suspensao Spring-Damper
// Estado de suspensao por roda
float suspension_force = wheel.ride_pos * typewheel.force; // spring F = k * x

// Integracao da mola
wheel.ride_vel += (-suspension_force - wheel.ride_vel * typewheel.dampening) * 0.02f * delta;
wheel.ride_pos += wheel.ride_vel * delta;

// Se a roda esta em contato
if (wclip.z <= tci.pos.z) {
  wheel.ride_pos += depth;   // empurrar para cima pela profundidade

  // Limite de compressao maxima
  float maxdepth = typewheel.radius * 0.7f;
  if (wheel.ride_pos > maxdepth) {
    float overdepth = wheel.ride_pos - maxdepth;
    wheel.ride_pos = maxdepth;
    perpforce -= overdepth * surfvel.z * typewheel.dampening * 5.0f;
  }

  // Vel. de suspensao nao pode ser negativa enquanto em contato
  if (wheel.ride_vel < -surfvel.z) wheel.ride_vel = -surfvel.z;
}

// Forca normal = suspensao + amortecimento
if (surfvel.z < 0.0f) perpforce -= surfvel.z * typewheel.dampening;

typewheel.force

Rigidez da mola (N/m). Quanto maior, mais rigida a suspensao.

typewheel.dampening

Amortecimento viscoso. Evita oscilacao. Valores tipicos: 10-50% da rigidez.

ride_pos

Compressao atual da mola (metros). Zero = repouso, positivo = comprimido.

6.Trigger Rally — Colisao com Paredes (Detalhes)

getContactInfo — Consulta ao Terreno

Para cada clip/roda, o sistema consulta a altura e normal do terreno em (x, y):

// tci.pos.x, tci.pos.y = posicao do clip no mundo
sim.getTerrain()->getContactInfo(tci);
// Retorna: tci.pos.z = altura do terreno
//          tci.normal = normal da superficie

Colisao com Paredes Verticais

Quando a geometria do nivel tem uma parede vertical (ex: margem da pista), o normal retornado sera horizontal. O processamento do clip e identico ao chao:

depth = (surface_point - clip_point) . normal

perpforce = depth * clip.force - (ptvel.normal) * clip.dampening

friction = -surfvel_tangential * 10000 (limitado a perpforce * 0.9)

F_total = normal * perpforce + surf_right * friction.x + surf_forward * friction.y

Para uma parede lateral (normal = X local), o resultado e:

  • perpforce → empurra o carro de volta para a pista (eixo X)
  • friction.y → desacelera o carro na direcao que corre paralela a parede (eixo Z = frente)
  • friction.x → friccao no eixo de deslizamento ao longo da parede
Limitacao do sistema de clips: Colisao apenas em pontos discretos, nao em faces. Para o Saturn isso e ideal — menos calculo, comportamento previsivel.
7.Trigger Rally — Sub-stepping
// sim.cpp: divisao do frame em sub-passos fixos de 5ms
float timeslice = 0.005f;                     // 5ms por sub-passo
int num = (int)(delta / timeslice) + 1;       // numeros de passos
timeslice = delta / (float)num;              // recalcula para preencher exato

for (int timestep = 0; timestep < num; ++timestep) {
  vehicle->tick(timeslice);   // calcular forcas
  body->tick(timeslice);      // integrar movimento
  vehicle->updateParts();     // atualizar posicao das partes
}
Para o Saturn (60 Hz): delta = 1/60 ≈ 16.7ms → num = 3-4 sub-passos por frame. O sub-stepping aumenta estabilidade numerica mas consome mais CPU. No Saturn, usar 1 passo por frame e mais realista dado o poder de processamento limitado.

9.Interlagos Racing — Slip Model (Dois Eixos)

Angulos de Deslizamento

alpha_front = steer_eff_rad - (vy + yawRate * lf) / |vx|
alpha_rear = 0 - (vy - yawRate * lr) / |vx|

Fy = clamp( -Ca * alpha, ±FyCap ) (saturacao de friccao) 
// car_dynamics_model.hpp ~linha 244
const Fxp steerEffRad = steerEffDeg * Tunables::kDegToRad;
const Fxp yawRateRadPerFrame = ioState.yawRateDegPerFrame * Tunables::kDegToRad;
const Fxp slipDenom = (vxAbs > Tunables::kSlipDenomMin) ? vxAbs : Tunables::kSlipDenomMin;

const Fxp vyFront = ioState.lateralSpeed + (yawRateRadPerFrame * Tunables::kWheelbaseFront);
const Fxp vyRear  = ioState.lateralSpeed - (yawRateRadPerFrame * Tunables::kWheelbaseRear);

const Fxp alphaFront = steerEffRad - (vyFront / slipDenom);
const Fxp alphaRear  = Fxp::BuildRaw(0) - (vyRear / slipDenom);

const Fxp fyFront = SaturateSigned(-Tunables::kLateralStiffnessFront * alphaFront, fyCap);
const Fxp fyRear  = SaturateSigned(-Tunables::kLateralStiffnessRear  * alphaRear,  fyCap);

Fxp lateralAccel = fyFront + fyRear + yawCoupling;
ioState.lateralSpeed += lateralAccel;
ioState.lateralSpeed -= ioState.lateralSpeed * Tunables::kLateralDampingCoeff;

const Fxp yawMoment = (fyFront * Tunables::kWheelbaseFront) - (fyRear * Tunables::kWheelbaseRear);
ioState.yawRateDegPerFrame += (targetYawRate - ioState.yawRateDegPerFrame) * Tunables::kYawRateResponse;
ioState.yawRateDegPerFrame -= ioState.yawRateDegPerFrame * Tunables::kYawDamping;

14.Plano — Aceleracao e Desaceleracao

Estado Atual

O modelo longitudinal usa uma tabela de aceleracao por gear (kGearAccelPerFrame[]). A velocidade maxima e controlada por drag implicito. Freio deduz throttle e ativa BrakeToStop.

Referencia Trigger Rally

  • Drive engine: wheel.spin_vel += drivetorque * drive * delta
  • Drag linear por eixo: frc = -vec3f(vx*drag.x, vy*drag.y, vz*drag.z)
  • Friccao de roda desacelera naturalmente pelo atrito

Melhorias Possiveis

Drag Proporcional a Velocidade (Nao Urgente)

Atual: freio subtrai constante do throttle. Melhor: drag F = -k * v^2 que naturalmente limita velocidade maxima e suaviza desaceleracao em coasting.

P3 Complexidade: baixa. Risco: pode alterar velocidade maxima — requer retuning de constantes.

Curva de Torque Realista (Nao Urgente)

Trigger Rally usa sistema de drive com DSysi (drive system instance) que modela curva de torque do motor. Para arcade Saturn: tabela simples de torque por velocidade seria suficiente.

P3 Complexidade: media. Risco: mudanca de feeling de aceleracao.

15.Plano — Curvas e Steering

Estado Atual

Dois modos: cinematico (speed < 2.5 u/f, yaw direto) e slip model (acima). Transicao suavizada por wasKinematic. Problema reportado: slide no inicio da curva parado.

Teste do Fix wasKinematic em Hardware

Os fixes implementados nesta sessao zerando yawRateDegPerFrame + yawAccumulatorDegRaw na saida do cinematico ainda nao foram validados em hardware Saturn.

P1 Cenarios de teste:

  • B + seta esquerda parado, segura → curva limpa sem slide
  • B + seta esquerda parado, solta rapido → carro para sem slide lateral
  • Curva em alta velocidade (> 2.5 u/f) → comportamento inalterado
  • Curva esquerda e direita → simetria perfeita

Speed-Dependent Steering (Influencia do Trigger Rally)

O Trigger Rally adiciona um componente de torque proporcional a velocidade * erro de yaw rate. Isso naturalmente reduz a resposta de steering em alta velocidade (mais seguro) e aumenta em baixa (mais manobravel).

Equivalente no nosso sistema: escalar kMaxYawRateDegPerFrame pelo inverso da velocidade, ou reduzir kLateralStiffnessFront/Rear em baixa velocidade.

// Ideia para implementar steering speed-dependent no cinematico:
// steer authority ja e calculado em funcao de velocidade (ver steerGate)
// Ajustar kMaxYawRateDegPerFrame por um fator de velocidade?
const Fxp speedFactor = Fxp::BuildRaw(1 << 16) / (vxAbs + Fxp::BuildRaw(1 << 16));
ioState.yawRateDegPerFrame = -(steerNorm * kMaxYawRateDegPerFrame * speedFactor);

P2 Complexidade: baixa. Risco: requer retuning do cinematico.

Suavizacao de Input (Referencia: PULLTOWARD)

O Trigger Rally usa PULLTOWARD (lerp) para suavizar o input de steering antes de aplicar torque. O Interlagos ja faz isso em TickCommandState (ver car_system.cxx linha 142). Verificar se os rates de suavizacao estao corretos para o feeling desejado.

16.Plano — Friccao Lateral

Comparacao dos Modelos

Aspecto Trigger Rally Interlagos Racing
Modelo base Rigidez infinita + clamping Linear Slip (tipo TORCS/VDrift)
Formula friction = -slip * 10000, clamp(perpforce) Fy = -Ca * alpha, clamp(FyCap)
Grip escalonavel Via typewheel.dampening Via surfaceGripScale
Saturacao Clamp circular (2D) Clamp por eixo (saturate signed)
Friccao longitudinal Integrada (spin_vel * radius) Separada (longitudinal controller)

Clamp Circular vs Clamp por Eixo

O Trigger Rally usa clamp circular para friccao (magnitude total ≤ maxfriction). O nosso usa clamp separado por eixo, o que pode gerar um "quadrado" de grip em vez de circulo. Em arcade puro isso nao importa, mas pode causar comportamentos estranhos na combinacao aceleracao + curva.

// Trigger Rally: clamp circular
float leng = friction.length();
if (leng > maxfriction) friction *= (maxfriction / leng);

// Interlagos: clamp por eixo (SaturateSigned)
const Fxp fyFront = SaturateSigned(fyFrontRaw, fyCap);
