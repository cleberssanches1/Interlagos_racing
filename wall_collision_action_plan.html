2.Causas Raiz do Traversal

Wall push perdido no early-exit de low-dynamics

Em car_ground_follower.hpp::UpdateTarget linhas 197–208:

if (canReuseLastSurface && ioState.surfaceProbeCooldown > 0u)
{
    --ioState.surfaceProbeCooldown;
    ioState.hasGroundSupport = true;
    ioState.correctionX = Fxp::BuildRaw(0);  // ← ZERA
    ioState.correctionZ = Fxp::BuildRaw(0);  // ← ZERA
    // retorna SEM chamar ProbeSurfaceTarget
    // wall push não é nem consultado nem aplicado
    return;
}

Efeito: quando o carro está em baixa dinâmica (parado ou velocidade baixa, steering pequeno), surfaceProbeCooldown > 0 por até 4 frames. Nesses frames o wall push é ZERO. O carro que está encostado em uma parede a baixa velocidade recebe push em apenas 1 de cada 4 frames — e o clamp de 1.20 u/frame não é suficiente para bloquear completamente.

Este é o bug principal para o caso de baixa velocidade. Carro parado pressionando contra parede → encosta lentamente e atravessa porque o push é aplicado só 25% dos frames.

Tunneling: sem teste swept, só posição pontual

FindPlanarWallPush testa apenas a posição atual contra as walls. Se o deslocamento de um frame for maior que o raio de colisão (kWallCollisionRadius = 1.25 u), o carro pode passar pelo lado oposto da parede sem detecção.

Caso de tunneling

Velocidade máxima = 7.125 u/frame
Raio de colisão = 1.25 u
Espessura mínima de parede ≈ 0 u (faces infinitely thin)

Em 1 frame: carro avança 7 u.
Se parede tem 0.5 u de espessura e o carro está a 0.6 u dela:
Frame anterior: 0.6 u de distância (dentro do raio 1.25) → push correto
Mas se a query falhar (bug 1) neste frame → carro avança para -6.5 u (outro lado)

Caso intermediário

Velocidade = 3 u/frame (120 km/h)
Raio = 1.25 u
Carro entra na zona de detecção, recebe push
Mas push é clampado a 1.20 u/frame
Carro ainda avança 3 - 1.2 = 1.8 u para dentro da parede
No próximo frame: mais push, mas penetração aumenta
Em 2-3 frames: traversal completo

Correção de posição não cancela velocidade

correctionX/Z apenas translada a posição, sem tocar em dynamicsState_.forwardSpeed ou dynamicsState_.lateralSpeed. No próximo frame, a física recalcula o deslocamento usando as mesmas velocidades → o carro é empurrado de volta para fora, depois entra de novo. Jitter ou traversal acumulado.

O correto é: quando wall push significativo é detectado, zerar o componente de velocidade perpendicular à parede.

kEnableBodyClipPlanarReaction = false no Saturn

// car_physics_shared.hpp linha 251
static constexpr bool kEnableBodyClipPlanarReaction =
    !kEnableSaturnLowCostPhysics;  // false no Saturn!

O sistema de clips (4 pontos no carro) está desabilitado no perfil Saturn. Com clips ativos, a detecção seria em 4 pontos da carroceria, cobrindo casos onde o centro do carro não toca a parede mas a lateral sim (curvas rasantes).

Motivo do disable: custo de 4 extra ResolvePlanarWallPush + 4 QuerySurface por frame. A QuerySurface é o custo caro — a wall query sozinha é barata.

3.Plano de Ação — Correções em Ordem de Prioridade

Preservar wall push no early-exit de low-dynamics

P1   Arquivo: src/car_ground_follower.hpp — função UpdateTarget (~linha 197)

Mudança: Antes de retornar no early-exit, aplicar lastWallPushX/Z se lastWallQueryHit == true.

// ANTES (linhas 197-208):

    ioState.edgeRightLost = false;

Anti-tunneling: clamp de posição pós-passo

P1   Arquivo: src/car_physics_v2.hpp — função StepOnce

Ideia: após ApplyVerticalAdhesion, se o wall push calculado neste frame é significativo, verificar se a nova posição ainda está no lado correto da parede. Se não, clampar.

Abordagem A — Wall query adicional no ponto de deslocamento máximo (simples)

Quando |displacement| > kWallCollisionRadius, fazer uma query extra na metade do caminho (midpoint check). Custo: 1 extra query em alta velocidade.

// car_physics_v2.hpp — em StepOnce, após ApplyVerticalAdhesion
if (trackQuery && Tunables::kEnableWallPlanarPush)
{
    const Fxp dispX = ioCarWorldPosition.X - preStepPosition.X;
    const Fxp dispZ = ioCarWorldPosition.Z - preStepPosition.Z;
    const Fxp dispMag = dispX.Abs() + dispZ.Abs();
    // Só faz o swept check se o deslocamento exceder o raio de detecção
    if (dispMag > Tunables::kWallCollisionRadius)
    {
        const Vector3D midPoint(
            preStepPosition.X + Fxp::BuildRaw(dispX.RawValue() / 2),
            ioCarWorldPosition.Y,
            preStepPosition.Z + Fxp::BuildRaw(dispZ.RawValue() / 2));
        Vector3D midWallPush{};
        int32_t midSegId = -1;
        const Vector3D fwd = Vector3D(stepOutput.sinYaw,
            Fxp::BuildRaw(0),
            Fxp::BuildRaw(-stepOutput.cosYaw.RawValue()));
        if (trackQuery->ResolvePlanarWallPush(midPoint, fwd,
                Tunables::kWallCollisionRadius, midWallPush, &midSegId, sampledSegmentId))
        {
            // Parede detectada no percurso: aplicar push imediatamente na posição final
            ioCarWorldPosition.X += Clamp(midWallPush.X,
                Fxp::BuildRaw(-Tunables::kMaxPlanarCorrectionPerFrame.RawValue()),
                Tunables::kMaxPlanarCorrectionPerFrame);
            ioCarWorldPosition.Z += Clamp(midWallPush.Z,
                Fxp::BuildRaw(-Tunables::kMaxPlanarCorrectionPerFrame.RawValue()),
                Tunables::kMaxPlanarCorrectionPerFrame);
            // Salvar para o frame de low-dynamics que pode reusar
            groundState_.lastWallQueryHit = true;
            groundState_.lastWallPushX = midWallPush.X;
            groundState_.lastWallPushZ = midWallPush.Z;
            if (midSegId > 0) groundState_.lastWallQuerySegmentId = midSegId;
        }
    }
}
Custo: 1 wall query extra apenas quando velocidade > 1.25 u/frame (~53 km/h). A query é local (seed segment ±2), portanto barata. Em alta velocidade o seed é confiável (carro se move progressivamente na pista).

Abordagem B — Swept segment test sem query extra (custo zero, recomendada para SH2)

Usar os wallSegments2D já cacheados do segmento atual. Fazer intersecção de segmento-vs-segmento 2D entre o vetor de deslocamento e cada wall do cache. Totalmente em inteiros, sem nova query ao TrackSystem.

// Teste de intersecção 2D (pré-computado no cache wallSegments2D)
// Custo: 5 segmentos × 4 arestas × ~10 operações = ~200 muls por frame em alta vel.

// Pseudocódigo:
auto segmentsIntersect(ax,az, bx,bz, cx,cz, dx,dz) -> bool
{

    int64_t d2 = cross(dx-cx,dz-cz, bx-cx,bz-cz);

    return ((d1>0&&d2<0)||(d1<0&&d2>0)) && ((d3>0&&d4<0)||(d3<0&&d4>0));
}

Cancelar velocidade perpendicular à parede

P1   Arquivo: src/car_physics_v2.hpp — função StepOnce

Quando wall push significativo é detectado (magnitude > threshold), projetar e cancelar a componente de velocidade que aponta para dentro da parede.

// Após acumular wallPushX/Z total do frame:
const Fxp pushMag = wallPushAccumX.Abs() + wallPushAccumZ.Abs();
if (pushMag > Tunables::kWallPushVelocityCancelThreshold) // ex: 0.10
{
    // Normalizar direção do push (aproximação barata: maior eixo)
    const Fxp absX = wallPushAccumX.Abs();
    const Fxp absZ = wallPushAccumZ.Abs();
    const Fxp nWallX = (absX >= absZ) ? Fxp::BuildRaw(1 << 16) : Fxp::BuildRaw(0);
    const Fxp nWallZ = (absZ > absX)  ? Fxp::BuildRaw(1 << 16) : Fxp::BuildRaw(0);
    // Sinal correto da normal
    const Fxp nX = (wallPushAccumX >= Fxp::BuildRaw(0)) ? nWallX : Fxp::BuildRaw(-nWallX.RawValue());
    const Fxp nZ = (wallPushAccumZ >= Fxp::BuildRaw(0)) ? nWallZ : Fxp::BuildRaw(-nWallZ.RawValue());

    // Velocidade no mundo
    const Fxp worldVelX = (stepOutput.sinYaw * dynamicsState_.forwardSpeed)
                         + (stepOutput.cosYaw * dynamicsState_.lateralSpeed);
    const Fxp worldVelZ = (Fxp::BuildRaw(-stepOutput.cosYaw.RawValue()) * dynamicsState_.forwardSpeed)
                         + (stepOutput.sinYaw * dynamicsState_.lateralSpeed);
    // Componente penetrando a parede (negativa = apontando para fora)
    const Fxp velDotNormal = (worldVelX * nX) + (worldVelZ * nZ);

    if (velDotNormal < Fxp::BuildRaw(0))  // velocidade aponta para dentro da parede
    {
        // Remover componente perpendicular à parede
        const Fxp cancelX = nX * velDotNormal;
        const Fxp cancelZ = nZ * velDotNormal;
        // Reconverter para espaço local do carro
        const Fxp cancelFwd = (cancelX * stepOutput.sinYaw) + (cancelZ * Fxp::BuildRaw(-stepOutput.cosYaw.RawValue()));
        const Fxp cancelLat = (cancelX * stepOutput.cosYaw)  + (cancelZ * stepOutput.sinYaw);
        dynamicsState_.forwardSpeed -= cancelFwd;
        dynamicsState_.lateralSpeed -= cancelLat;
    }
}
Resultado esperado: Carro "para" ao tocar a parede em vez de continuar empurrando. Deslizamento ao longo da parede funciona naturalmente (componente paralela não é cancelada).

Constante necessária

Adicionar em car_physics_shared.hpp::Tunables:

static constexpr Fxp kWallPushVelocityCancelThreshold = Fxp::BuildRaw(0x00001999); // 0.10
