1. Pipeline de frame

Pools dominantes por etapa. Solo/paredes = TCOL.BIN (Cart), independente de TRACK_LOD0_SEGMENTS=0.

1. Boot / CD CAR1, PATH, packs → Cart. B1: sem TRKRDR high se lod0=0.
2. Track belt GEO low TRKRDRL em LWR; tex 64² via TBKLOD0 → VDP1.
3. TCOL Solo/paredes LOD0 offline em Cart. Não usa TBKLOD.
4. Simulação Física/Auto Lap em HWR .text. PATH + rota NPC em LWR.
5. Render 3D Pista + carro + 1 NPC reuse → SGL → VDP1.
6. HUD / céu VDP2 NBG. C3: bitmap céu só em VRAM (LWR0). MEM10 / SEGCAP.

2. Módulos do motor

O Interlagos é um motor Saturn próprio: esteira de segmentos, fundo/céu, carro 3D, física/plant e som do motor. Cada módulo pressiona pools diferentes — o gráfico abaixo usa ordens de grandeza (KiB de asset dominante + orçamento de faces), não um profiler por frame.

Esteira de segmentos

TrackSystem: janela LOD (hoje 0/20/0), GEO low TRKRDRL, texturas TBKLOD0 64², submit SGL→VDP1.

LWR GEO/MAT Cart packs VDP1 tex ~1350 faces

Background / céu

SkyPanorama → NBG0 VDP2. Após C3 o bitmap LWR é libertado (SPN … LWR0); o scroll usa só VRAM.

VDP2 NBG0 LWR0 pós-upload

Carro 3D

Mesh CAR1.NYA + MeshRenderer (jogador; NPC reutiliza o mesmo mesh quando rails=1). ~118 faces no orçamento SGL.

Cart ~47 KiB VDP1 / SGL .text render

Física / plant

CarPhysics + mapa TCOL.BIN (solo/paredes) no Cart. Independente do LOD visual. PATH/Auto Lap em LWR quando HWR está apertada.

TCOL ~917 KiB .text sim PATH ~11 KiB

Som do carro

Loop motor ENGSD.WAV no driver SGL/SCSP. Pitch no Master; one-shots sob AUDIO_PROFILE.

3. Capacidades vs MEM10 livre (log8)

Barras da esquerda = capacidade estrutural. Direita = livre KiB em log5 (pré-gate) vs log8 (pós-gate TBKLOD2, pré-B1). Cart +89 KiB; H/L/V1/V2 iguais nesse instante. Reteste B1 deve mostrar MEM10 C: ~+800–1200 vs log8.
