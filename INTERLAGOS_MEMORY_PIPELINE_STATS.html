1. Pipeline de frame

Pools dominantes por etapa. Solo/paredes = TCOL.BIN (Cart), independente de TRACK_LOD0_SEGMENTS=0.

1. Boot / CD CAR1, PATH, packs → Cart. High GEO ainda pode residir (ver §5).
2. Track belt GEO low TRKRDRL em LWR; tex 64² via TBKLOD0 → VDP1.
3. TCOL Solo/paredes LOD0 offline em Cart. Não usa TBKLOD.
4. Simulação Física/Auto Lap em HWR .text. PATH + rota NPC em LWR.
5. Render 3D Pista + carro + 1 NPC reuse → SGL → VDP1.
6. HUD / céu VDP2 NBG/RBG. MEM10 amostra livres.
