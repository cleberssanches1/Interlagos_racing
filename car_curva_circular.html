1. Sistema de Coordenadas

Todo o desenvolvimento usa o sistema de coordenadas mão-direita com os seguintes eixos:

Eixo Z — Frontal

Direção para onde o carro aponta quando θ = 0°. +Z = frente.

Eixo X — Lateral

+X = direita do carro (quando θ = 0°). Curva à esquerda → X diminui.

Eixo Y — Vertical

+Y = cima. O movimento planar ignora Y; a física lateral ocorre no plano XZ.

Ângulo de Yaw θ

Rotação em torno de Y. Positivo = horário visto de cima (gira à direita). Curva à esquerda → θ decresce.

2. Modelo Cinemático de Bicicleta

O modelo cinemático de bicicleta reduz o carro a dois eixos (dianteiro e traseiro) e assume que as rodas não derrapam — velocidade de cada roda é tangente à sua trajetória. É a base de todos os modelos de física veicular de jogos.

Por que "bicicleta"? As duas rodas de cada eixo são fundidas numa só roda central. Isso simplifica os cálculos sem perder a essência da curvatura.

3. Fórmulas Centrais

3.1 Raio de Curvatura

Quando as rodas dianteiras formam ângulo δ com o eixo do veículo, a geometria de Ackermann garante que o eixo traseiro descreve um arco de raio:

Raio de curvatura (eixo traseiro) R = L / tan(|δ|) L = entre-eixos (distância dianteiro → traseiro) δ = ângulo de esterçamento das rodas dianteiras (rad) R → ∞ quando δ → 0 (linha reta) R mínimo quando |δ| = máximo (maior curvatura possível)
Intuição geométrica: Imagine prolongar o eixo traseiro e o eixo das rodas dianteiras esterçadas até que se cruzem. O ponto de cruzamento é o centro instantâneo de rotação. A distância desse ponto ao eixo traseiro é exatamente R.

3.2 Velocidade Angular (Taxa de Yaw)

Se o carro percorre um arco de raio R a velocidade v, a taxa de variação do heading é:

Velocidade angular (rad/frame) ω = v / R = v · tan(δ) / L Curva à esquerda: δ < 0 → ω < 0 → θ decresce Curva à direita: δ > 0 → ω > 0 → θ aumenta

3.3 Direção de Movimento no Espaço Mundial

Para o sistema Z-frente, X-direita, com heading θ (rad, relativo a +Z):

Vetor direção (plano XZ) forward.X = sin(θ) forward.Z = cos(θ) θ=0° → forward = (0, 0, 1) aponta +Z ✓ θ=90° → forward = (1, 0, 0) aponta +X (virou 90° à direita)

3.4 Atualização de Posição por Frame

A cada frame de duração Δt, o carro avança v·Δt na direção forward calculada antes da atualização do yaw (integração de Euler explícita):

Integração por frame (Euler explícito) 1. θ_novo = θ_atual + ω · Δt 2. ΔX = sin(θ_atual) · v · Δt 3. ΔZ = cos(θ_atual) · v · Δt 4. X_novo = X_atual + ΔX 5. Z_novo = Z_atual + ΔZ
Nota sobre acumulador sub-grau: Em implementações de ponto fixo, ω por frame pode ser menor que 1°. Use um acumulador: adicione ω ao acumulador a cada frame e aplique ao yaw inteiro somente quando o acumulador atingir ±1°. Isso elimina truncamento prematuro que distorce o raio real.

3.5 Circunferência e Tempo para Completar 360°

Volta completa (360°) Circunferência = 2π · R = 2π · L / |tan(δ)| Tempo (frames) = 2π · R / v = 2π · L / (|v| · |tan(δ)|) Quanto menor |δ| (rodas quase retas), maior o raio e mais frames para completar. Quanto maior |v|, menos frames para completar (mesmo raio).

5. Implementação em C++

5.1 Estruturas de Dados

#pragma once
#include <cmath>
#include <algorithm>
#include <cstdint>

// ─────────────────────────────────────────────────────────
//  Sistema de coordenadas:
//    Z = frente  (forward)
//    X = direita (lateral)
//    Y = cima    (vertical, ignorado na física planar)
//  Yaw θ positivo = horário visto de cima (virar à direita).
//  Yaw θ negativo = curva à esquerda.
// ─────────────────────────────────────────────────────────

struct Vec3
{
    float x, y, z;
    Vec3(float x = 0.f, float y = 0.f, float z = 0.f) : x(x), y(y), z(z) {}
};

// Parâmetros físicos do veículo (configuração estática).
struct VehicleParams
{
    float wheelbase       = 2.0f;   // L — entre-eixos (u)
    float maxSteerDeg     = 30.0f;  // ângulo máximo das rodas (graus)
    float accelPerFrame   = 0.5f;   // aceleração longitudinal (u/frame²)
    float maxSpeed        = 20.0f;  // velocidade máxima (u/frame)
    float steerResponse   = 0.20f;  // lerp da roda por frame [0,1]
};

// Estado dinâmico do carro — atualizado a cada frame.
struct CarState
{
    Vec3    position     = {};       // posição no espaço mundial (X, Y, Z)
    float   yawDeg       = 0.f;    // heading (°), positivo = horário
    float   yawAccum     = 0.f;    // acumulador sub-grau (°)
    float   forwardSpeed = 0.f;    // velocidade longitudinal (u/frame)
    float   steerDeg     = 0.f;    // ângulo físico atual das rodas (°)
};

// Entradas do jogador por frame.
struct DriverInput
{
    float  throttle   = 0.f;  // [0, 1]   — acelerador
    float  steerNorm  = 0.f;  // [−1, +1] — seta (−1=esq, +1=dir)
    bool   braking    = false; // freio
};

5.2 Funções Auxiliares

// Converte graus para radianos.
inline float ToRad(float deg) { return deg * (3.14159265f / 180.f); }
inline float ToDeg(float rad) { return rad * (180.f / 3.14159265f); }

// Normaliza um ângulo para o intervalo [−180°, +180°).
float NormalizeYaw(float deg)
{
    deg = std::fmod(deg, 360.f);
    if (deg >  180.f) deg -= 360.f;
    if (deg <= -180.f) deg += 360.f;
    return deg;
}

// Calcula o raio de curvatura a partir do ângulo de esterçamento.
// Retorna um valor muito grande (quase infinito) para esterçamento nulo.
float TurnRadius(float steerDeg, float wheelbase)
{
    const float tanSteer = std::tan(ToRad(std::abs(steerDeg)));
    if (tanSteer < 1e-6f) return 1e9f; // linha reta
    return wheelbase / tanSteer;
}

// Velocidade angular (graus/frame) para dado esterçamento e velocidade.
// Negativa = curva à esquerda (steerDeg negativo).
float YawRateDegPerFrame(float forwardSpeed, float steerDeg, float wheelbase)
{
    // ω = v · tan(δ) / L  →  em graus/frame = ω_rad · (180/π)
    const float steerRad  = ToRad(steerDeg);
    return ToDeg(forwardSpeed * std::tan(steerRad) / wheelbase);
}

5.3 Função Principal de Integração por Frame

// Integra a física planar do carro por um frame.
// Implementa o modelo cinemático de bicicleta com acumulador sub-grau.
//
//  Ordem de operações por frame:
//  1. Atualiza velocidade longitudinal (aceleração/freio).
//  2. Lerpa ângulo de esterçamento das rodas em direção ao input.
//  3. Calcula velocidade angular (ω) pelo modelo cinemático.
//  4. Acumula ω no acumulador sub-grau e aplica yaw inteiro.
//  5. Avança posição na direção forward (usando yaw PRÉ-rotação).
void IntegrateKinematics(const DriverInput&    input,
                         const VehicleParams& params,
                               CarState&       state)
{
    // ── 1. Velocidade longitudinal ──────────────────────────────────
    if (input.braking)
    {
        state.forwardSpeed *= 0.85f; // frenagem: decaimento rápido
        if (std::abs(state.forwardSpeed) < 0.01f)
            state.forwardSpeed = 0.f;
    }
    else if (input.throttle > 0.f)
    {
        state.forwardSpeed += input.throttle * params.accelPerFrame;
        state.forwardSpeed  = std::min(state.forwardSpeed, params.maxSpeed);
    }
    else
    {
        state.forwardSpeed *= 0.97f; // arrasto em rolagem (coast)
    }

    // ── 2. Esterçamento das rodas (lerp em direção ao target) ───────
    //   steerNorm ∈ [−1, +1], negativo = esquerda, positivo = direita
    //   O lerp impede mudança instantânea (simula inércia do volante).
    const float targetSteerDeg = input.steerNorm * params.maxSteerDeg;
    state.steerDeg += (targetSteerDeg - state.steerDeg) * params.steerResponse;

    // ── 3. Velocidade angular (modelo cinemático de bicicleta) ──────
    //   ω = v · tan(δ) / L
    //   Sinal de steerDeg determina direção: − = esquerda, + = direita.
    const float yawRateDeg = YawRateDegPerFrame(
        state.forwardSpeed, state.steerDeg, params.wheelbase);

    // ── 4. Acumulador sub-grau e atualização do yaw ─────────────────
    //   Em ponto fixo ou inteiro, yawRateDeg por frame pode ser < 1°.
    //   Somar direto causaria truncamento e o raio real seria maior que
    //   o esperado. O acumulador preserva a fração sub-grau entre frames.
    state.yawAccum += yawRateDeg;

    const float yawStep = std::trunc(state.yawAccum); // parte inteira (truncamento)
    state.yawAccum  -= yawStep;                          // mantém o resíduo
    state.yawDeg   += yawStep;
    state.yawDeg    = NormalizeYaw(state.yawDeg);

    // ── 5. Posição: avança na direção forward PRÉ-rotação ───────────
    //   Usa o yawDeg ANTES do passo atual para que o deslocamento
    //   seja tangente ao arco (integração de Euler explícita).
    const float yawRad   = ToRad(state.yawDeg);
    state.position.x  += std::sin(yawRad) * state.forwardSpeed;
    state.position.z  += std::cos(yawRad) * state.forwardSpeed;
    // position.y permanece inalterado (física planar)
}

5.4 Função de Verificação — Arco Completo de 360°

// Verifica se o carro completou um giro de 360° desde um yaw de referência.
// Rastreia a variação acumulada de yaw para lidar com o wraparound ±180°.
struct CircleTracker
{
    float   totalYawDeg   = 0.f;
    float   prevYawDeg    = 0.f;
    bool    initialized   = false;

    void Reset(float currentYaw)
    {
        totalYawDeg = 0.f;
        prevYawDeg  = currentYaw;
        initialized = true;
    }

    // Atualiza com o yaw atual do carro; retorna true quando 360° concluídos.
    bool Update(float currentYaw)
    {
        if (!initialized) { Reset(currentYaw); return false; }

        // Delta com correção de wraparound.
        float delta = currentYaw - prevYawDeg;
        if (delta >  180.f) delta -= 360.f;
        if (delta <= -180.f) delta += 360.f;

        totalYawDeg += delta;
        prevYawDeg   = currentYaw;

        // 360° à esquerda: totalYawDeg ≤ −360°
        // 360° à direita:  totalYawDeg ≥ +360°
        return std::abs(totalYawDeg) >= 360.f;
    }

    float Progress() const
    {
        return std::min(std::abs(totalYawDeg) / 360.f, 1.f);
    }
};

5.5 Programa Principal — Simula 360° à Esquerda

#include <iostream>
#include <iomanip>
// (inclua os headers das funções acima)

int main()
{
    VehicleParams params;
    params.wheelbase     = 2.0f;
    params.maxSteerDeg   = 25.0f;
    params.accelPerFrame = 0.3f;
    params.maxSpeed      = 8.0f;
    params.steerResponse = 0.15f;

    CarState car;  // posição (0,0,0), yaw 0°, repouso

    // Input: acelerador 100%, seta esquerda (−1.0)
    DriverInput input;
    input.throttle  = 1.0f;
    input.steerNorm = -1.0f; // esquerda
    input.braking   = false;

    CircleTracker tracker;
    tracker.Reset(car.yawDeg);

    std::cout << std::fixed << std::setprecision(2);
    std::cout << "Frame | Speed  | SteerDeg | YawDeg  | X       | Z       | Progresso\n";
    std::cout << "-------+--------+----------+---------+---------+---------+----------\n";

    for (int frame = 0; frame < 2000; ++frame)
    {
        IntegrateKinematics(input, params, car);
        const bool done = tracker.Update(car.yawDeg);

        if (frame % 10 == 0 || done)
        {
            std::cout
                << std::setw(5)  << frame
                << " | " << std::setw(6)  << car.forwardSpeed
                << " | " << std::setw(8)  << car.steerDeg
                << " | " << std::setw(7)  << car.yawDeg
                << " | " << std::setw(7)  << car.position.x
                << " | " << std::setw(7)  << car.position.z
                << " | " << std::setprecision(1) << (tracker.Progress() * 100.f) << "%"
                << "\n";
        }

        if (done)
        {
            std::cout << "\n360° concluídos no frame " << frame
                      << "  |  posição final X=" << car.position.x
                      << "  Z=" << car.position.z << "\n";
            break;
        }
    }
    return 0;
}

Regra prática: Dobrar o ângulo de esterçamento (ex.: 10° → 20°) aproximadamente dobra a curvatura (raio cai à metade) para ângulos pequenos, pois tan(δ) ≈ δ (rad) para δ pequeno. Para ângulos grandes a relação não é linear.

7. Casos Especiais e Boas Práticas

7.1 Lançamento do Repouso (v = 0)

  1. ω = 0 no primeiro frame — com v = 0, a fórmula ω = v·tan(δ)/L = 0 independentemente do esterçamento. Nenhum yaw ocorre no frame zero.
  2. Curva começa no frame 1 — após a velocidade crescer no frame 0 (pela aceleração), o frame 1 já tem v > 0 e ω ≠ 0. O carro começa a girar imediatamente na direção correta.
  3. Acumulador sub-grau deve estar limpo — se o carro veio de uma curva anterior no sentido oposto, o acumulador pode ter resíduo de sinal errado. Zerá-lo ao detectar troca de direção impede um passo de yaw errado no primeiro frame.

7.2 Troca de Direção (Direita → Esquerda)

Problema do lag do esterçamento: O steerDeg lerpa com resposta 0.20/frame. Ao trocar de +100% direita para −100% esquerda, o steerDeg leva ~2–3 frames para cruzar zero. Nesse período a fórmula ω = v·tan(steerDeg)/L produz yaw na direção errada. Solução: suprimir ω (→ 0) enquanto o sinal do input raw discordar do sinal do steerDeg. 
// Supressão durante a transição de direção.
const bool steerTransitioning =
    (input.steerNorm < 0.f && state.steerDeg > 0.f) ||
    (input.steerNorm > 0.f && state.steerDeg < 0.f);

float effectiveYawRate = steerTransitioning ? 0.f :
    YawRateDegPerFrame(state.forwardSpeed, state.steerDeg, params.wheelbase);

if (steerTransitioning)
    state.yawAccum = 0.f; // limpa resíduo de sinal oposto

7.3 Proteção contra Divisão por Zero

// Impede tan(90°) = infinito e raio zero.
constexpr float kMaxSteerRad = ToRad(89.0f);
const float clampedSteer = std::clamp(ToRad(steerDeg),
                                         -kMaxSteerRad, kMaxSteerRad);

7.4 Aceleração Variável e Raio Dinâmico

Quando o carro acelera durante a curva (v cresce a cada frame), o raio do arco varia porque ω = v·tan(δ)/L cresce com v enquanto δ é constante. O círculo perfeito só ocorre a velocidade constante. Para simular espirais de aceleração use a integração frame a frame apresentada — ela trata isso automaticamente.

8. Fluxo Completo por Frame

Entrada do jogador
throttle, steerNorm, braking
↓
1. Velocidade longitudinal
forwardSpeed += throttle · accel (ou decaimento)
↓
2. Esterçamento físico das rodas
steerDeg += (targetSteer − steerDeg) · steerResponse
↓
3. Detecção de transição de direção
se sinal(input) ≠ sinal(steerDeg) → yawRate = 0, limpa acum
↓
4. Velocidade angular (modelo cinemático)
yawRate = forwardSpeed · tan(steerDeg) / wheelbase
↓
5. Acumulador sub-grau → passo inteiro de yaw
yawAccum += yawRate → yawDeg += trunc(yawAccum)
↓
6. Atualização de posição (Euler explícito)
pos.X += sin(yawDeg) · forwardSpeed
pos.Z += cos(yawDeg) · forwardSpeed
↓
Estado atualizado — pronto para renderização
